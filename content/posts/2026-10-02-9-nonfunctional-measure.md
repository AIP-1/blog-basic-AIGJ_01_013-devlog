팀에서 **비기능 요구사항**을 맡았다. 기능 요구사항이 "무엇을 하는가"라면, 비기능은 **"얼마나 안전하고, 빠르고, 쓰기 편한가"**다.

말로만 "안전하다"라고 쓰면 지켰는지 알 수 없다. 그래서 항목마다 **검증 방법**을 붙이고, 상태(✅)는 **직접 확인한 것만** 표시했다.

## 정리한 항목 (26개)

| 분류 | 예시 |
|---|---|
| 보안 | 비밀값 관리, 서버 권한 검사, XSS, 비밀번호 해시, 로그인 시도 제한, 쿠키, CSRF, SQL 인젝션 |
| 무결성 | 트랜잭션, 동시 출석, DB 제약조건, 잔액은 원장 합계로 |

| 성능·호환성·운영 | 1초 안에 표시, 브라우저, 자동 배포, 마이그레이션, 백업 |

## 직접 확인한 것

### 로그인 쿠키

```text
set-cookie: better-auth.session_token=...; Max-Age=604800; Path=/; HttpOnly; SameSite=Lax
```

- `HttpOnly`: 자바스크립트로 쿠키를 읽을 수 없다 (XSS로 쿠키를 훔쳐 가지 못함)
- `SameSite=Lax`: 다른 사이트에서 보내는 POST 요청에는 쿠키가 실리지 않는다
- `Secure`(HTTPS에서만 전송)는 로컬이 http라 없다 → 배포 후 다시 확인

### CSRF (다른 사이트에서 몰래 요청 보내기)

로그인 쿠키를 가진 채로 `Origin`만 다른 사이트로 바꿔 로그아웃 요청을 보내 봤다.

```text
Origin: https://evil.example   → 403 {"code":"INVALID_ORIGIN"}
Origin: http://localhost:3000  → 200 {"success":true}
```

### XSS (글에 스크립트 심기)

글 저장 경로와 똑같은 정화 함수에 공격 문자열 6개를 넣었다.

```text
✅ <script>alert(1)</script>            → 제거
✅ <img src=x onerror="alert(1)">       → 제거
✅ <a href="javascript:alert(1)">       → 주소만 제거
✅ <p onclick="alert(1)">               → 속성 제거
✅ <iframe>, <style>                    → 제거
✅ 정상 글(제목, 굵게, 링크, 코드)      → 그대로
```

팀원도 `npm run test:sanitize`로 다시 돌릴 수 있게 저장소에 넣었다.

### 속도

배포와 같은 **프로덕션 빌드**를 따로 띄워서 쟀다. 개발 서버는 실제보다 느리다.

| 항목 | 결과 |
|---|---|
| `/feed` 서버 응답 (5회 중앙값) | 6ms |
| `/feed` 화면 완성 | 87ms |

목표(1초)보다 훨씬 빠르지만, **내 컴퓨터 + 데이터가 거의 없는 상태**라 의미가 크지 않다. 배포 후, 글을 많이 넣은 뒤 다시 잰다.

## 숫자로는 안 보이는 문제

모바일(375px)에서 모든 화면의 **가로 스크롤**을 측정했더니 8개 화면 모두 통과였다. 그런데 스크린샷을 눈으로 보니 문제가 있었다.

1. **헤더 메뉴가 숨는다**: "광장"만 보이고 나머지는 숨겨진 가로 스크롤 안에 있다.
2. **버튼 글자가 쪼개진다**: [글쓰기] 버튼이 "글쓰 / 기"로 두 줄이 된다.

> 측정은 "가로 스크롤이 없다"만 확인했을 뿐, "쓰기 편하다"를 확인한 게 아니었다. **측정 + 눈으로 확인** 둘 다 필요하다.

## 아직 못 지키는 것

- **로그인 시도 제한**: 라이브러리에 "10초에 3번" 제한이 있지만 HTTP 요청에만 걸린다. 우리 로그인은 서버 코드(Server Action)에서 라이브러리를 직접 불러서 적용되지 않을 수 있다. → 보완 필요로 기록
