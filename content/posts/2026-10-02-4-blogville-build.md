설계를 끝내고 Claude와 함께 하루 동안 기본 기능을 모두 만들었다.

## 만든 것

| 분류 | 기능 |
|---|---|
| 회원 | 네이버·카카오·구글 로그인 설정, 개발용 로그인, 온보딩 |
| 광장 | Phaser 2D 마을: 걷기·충돌, 건물 상호작용, 최근 글 쓴 이웃집 |
| 블로그 | `/@주소` 블로그 홈(미니룸), 에디터, 카테고리, 태그, 공개/비공개 |
| 교류 | 공감, 댓글·답글, 이웃, 마을 소식 |
| 게임 | 레벨, 코인, 출석, 상점, 꾸미기 |

캐릭터와 배경 그림은 아직 **이모지와 그라데이션**이다. DB에는 그림의 이름표(`asset_key`)만 저장해서, 나중에 픽셀아트로 바꿔도 DB는 건드릴 필요가 없다.

## 개발용 로그인

소셜 로그인은 개발자 센터에서 키를 발급받아야 테스트할 수 있다. 키를 받기 전에도 개발할 수 있도록 **개발 환경에서만 켜지는 임시 계정 로그인**을 만들었다. 배포 환경에서는 자동으로 꺼진다.

## 실제 브라우저로 테스트: Playwright

이 Mac에는 Chrome이 없어서 Playwright로 테스트용 Chromium을 받아 **가입 → 글쓰기 → 다른 회원의 공감·댓글 → 보상**을 자동으로 돌리고 스크린샷으로 확인했다.

| 사람 | 동작 | 코인 |
|---|---|---|
| tester1 | 가입 축하 | 100 |
| tester1 | 글 발행 (+30) | 130 |
| tester2 | 남의 글에 댓글 (+5) | 105 |
| tester1 | 공감 받음 (+2) | 132 |

## 트러블슈팅

### 1. 보상을 받았는데 헤더 코인이 그대로

DB에는 들어갔는데 화면 위쪽 코인 숫자가 안 바뀌었다. 원인은 Next.js가 페이지를 이동해도 **레이아웃(헤더)은 다시 그리지 않는다**는 것이었다. 보상이 생기는 동작 뒤에 레이아웃까지 다시 그리게 했다.

```ts
revalidatePath("/", "layout");
```

### 2. 에디터 툴바를 누르면 커서가 사라짐

H2 버튼을 누르고 글을 쓰면 빈 제목 줄이 생기고 글은 아래 문단으로 들어갔다. **버튼이 포커스를 가져가면서** 에디터의 커서 위치를 잃은 것이다.

```tsx
<button onMouseDown={(e) => e.preventDefault()} ... />
```

### 3. 캐릭터가 지붕 위에 그려짐

광장에서 집 뒤로 걸어가도 캐릭터가 지붕 위에 보였다. 게임에서 흔히 쓰는 **y-sorting**(아래쪽에 있을수록 앞에 그리기)을 넣었다.

```ts
this.player.setDepth(this.player.y + 20);
```

### 4. 카카오 로그인은 이메일을 안 줄 수 있다

로그인 라이브러리는 이메일이 없으면 로그인을 거부한다. 그런데 카카오는 개인 개발자 앱에서 이메일 동의항목을 쓰기 어렵다. 라이브러리 코드를 직접 열어서 확인한 뒤, 닉네임·프로필 사진만 요청하고 이메일 자리에는 대체 주소(`kakao_ID@kakao.blogville.invalid`)를 넣게 했다.

### 5. `.env.example`이 GitHub에 안 올라감

`.gitignore`의 `.env*` 규칙이 비밀값 파일(`.env.local`)뿐 아니라 **예시 파일까지** 막고 있었다. 예외를 추가했다.

```text
.env*
!.env.example
```
