과제를 받고 바로 첫 버전을 만들었다. 프레임워크 없이 **HTML, CSS, JavaScript**만 사용했다.

## Tistory에서 참고한 것

- 상단 헤더 + 본문 + 오른쪽 사이드바 구조
- 사이드바의 프로필, 카테고리(글 수), 최근 글, 방문자 수
- 글 목록의 썸네일과 요약

## 해시 라우팅

페이지가 하나(`index.html`)뿐이라서 주소의 `#` 뒷부분으로 화면을 바꾼다.

```js
window.addEventListener("hashchange", render);
```

`#/post/5`면 5번 글, `#/category/Git`이면 Git 카테고리 목록을 그리는 식이다.

## 다크 모드

색을 CSS 변수로 정해 두고, `html` 태그의 `data-theme` 값만 바꿔서 전체 색을 한 번에 바꿨다.

```css
:root               { --bg: #f5f6f8; --text: #222; }
[data-theme="dark"] { --bg: #16181d; --text: #e6e6e6; }
```
