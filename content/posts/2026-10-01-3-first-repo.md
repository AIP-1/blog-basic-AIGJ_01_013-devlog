처음으로 내 저장소를 만들어서 GitHub에 올려봤다. 순서대로 기록해 둔다.

## 1. 로컬 저장소 만들기

```bash
mkdir my-first-repo
cd my-first-repo
git init
```

`git init`을 하면 폴더 안에 `.git` 디렉터리가 생기고, 이때부터 Git이 변경 사항을 추적한다.

## 2. 첫 커밋

```bash
git status          # Untracked 파일 확인
git add README.md   # 스테이징
git commit -m "첫 커밋: README 추가"
```

`add`는 "이번에 기록할 파일 고르기", `commit`은 "실제로 기록하기"라고 이해하면 쉽다.

## 3. GitHub에 올리기

GitHub CLI(`gh`)를 쓰면 저장소 생성, 원격 연결, push를 한 줄로 끝낼 수 있다.

```bash
brew install gh
gh auth login --web
gh repo create my-first-repo --private --source=. --push
```

### 삽질 기록

> `fatal: could not read Username for 'https://github.com'` 에러가 났다.
> `gh auth setup-git`을 한 번 실행해서 Git이 gh 로그인 정보를 쓰도록 연결하니 해결됐다.
