오늘은 회의로 시작해서 PR 정리로 끝났다.

## 1. 회의 안건을 문서로

회의 전에 안건 문서를 만들었다. 안건마다 **선택지와 따져볼 점**을 적어 두고, 맨 아래에 회의 중에 채울 **결정 기록 표**를 뒀다. 회의하면서 팀원들이 문서를 직접 고쳤고, 끝나고 그 문서를 그대로 읽어서 할 일을 정리했다.

| 안건 | 결정 |
|---|---|
| 출석 1~3등 코인 보상 | 반려 |
| 동물 농장 | 알에서 랜덤 부화, 한 번에 5마리, 동물마다 다른 성장치·보상, 글을 쓰면 동물도 자람, 다 키우면 카드 |
| 모바일 | 휴대폰에서는 광장 대신 큰 버튼 메뉴만 보이는 간단 버전 |
| 접근성(NF-17) | 하지 않는다 |
| 마감 | 10/16 (ERD 제출은 10/9) |

> 회의에서 "실제 돈으로 촉진제를 사게 하자"는 이야기도 나왔는데, 수업 프로젝트에서 실제 결제는 하기 어려워서 **코인으로만** 사게 정리했다.

## 2. 하루 동안 머지한 PR

| PR | 내용 |
|---|---|
| #30, #32, #33, #35 | 이상한 숫자 주소 500 → 404, 글자 수 화면·서버 일치, 미니룸 테두리, 오류 화면 (창근) |
| #36 | 글에 사진·파일 첨부 (창근) |
| #40 | 블로그 방문자 수 (창근) |
| #41 | 휴대폰 간단 버전 + 모바일 이슈 #5 (지원) |
| #38, #42 | 동물 농장 1차, 테스트 타이밍 수정 (나) |
| #31, #37, #39 | 요구사항 문서 정리 (창근) |

리뷰할 때는 PR들을 **내 컴퓨터에서 main에 한꺼번에 합쳐 보고** 전체 테스트를 돌린 뒤 승인했다. 하나씩은 괜찮아도 같이 합치면 깨지는 경우가 있기 때문이다.

첨부 기능 PR에서는 보안을 특히 봤다. 다른 사이트에서 몰래 보낸 요청 막기, 확장자만 바꾼 가짜 사진 걸러내기, 파일 이름에 경로 문자 막기, 내려받은 파일이 브라우저에서 실행되지 않게 하기 등이 다 들어 있었다. 대신 **Vercel에 배포하면 서버 디스크에 올린 파일이 사라진다**는 점을 리뷰로 남겼다.

## 3. 같은 파일을 여럿이 고치면 생기는 일

### 마이그레이션 번호가 겹쳤다

첨부 PR과 내 농장 PR이 둘 다 `0004`번 마이그레이션을 만들었다. 첨부를 먼저 머지하고, 농장 마이그레이션은 지운 뒤 다시 만들어서 `0005`가 되게 했다.

더 곤란했던 건 **내 컴퓨터 DB**였다. 농장(0004, 나중 날짜)을 먼저 적용한 상태에서 첨부(0004, 이른 날짜)를 적용하려 하자, Drizzle이 "이미 지난 마이그레이션"으로 보고 **조용히 건너뛰었다**. 오류도 없이 테이블만 안 생겼다.

```bash
psql "$DATABASE_URL" -c "SELECT to_regclass('attachments')"   # 비어 있음 → 안 만들어졌다
```

개발용 데이터만 있어서 DB를 지우고 처음부터 다시 만들었다.

### 문서 버전 번호가 계속 겹쳤다

요구사항 문서는 PR마다 변경 이력에 한 줄을 더한다. 동시에 여러 PR이 열리니 1.6이 두 개, 1.7이 두 개가 됐다. **머지한 순서대로** 번호를 다시 매겨서 1.4 → 1.5 → 1.6 → 1.7 → 1.8 → 1.9로 맞췄다.

> 번호를 미리 정하지 말고, 머지할 때 정하는 규칙이 필요하다.

### PR 없이 main에 바로 올라온 커밋

팀원 한 명이 문서를 PR 없이 main에 직접 올렸다. 그래서 버전 번호가 또 겹쳤다. 팀 규칙(브랜치 → PR → 승인)을 다시 알렸다.
